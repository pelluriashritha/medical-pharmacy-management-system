Medical Pharmacy Management System

Project Description

The Medical Pharmacy Management System is a Java-based application connected to a MySQL database. It helps manage patient records, doctor records, medicines, prescriptions, and billing.

Technologies Used

- Java
- Object-Oriented Programming (OOPS)
- MySQL
- JDBC
- VS Code
- MySQL Connector/J

Main Features

1. Patient Registration
2. Doctor Registration
3. Medicine Registration
4. Prescription Registration
5. Prescription Details
6. Bill Generation
7. View Patient Records
8. View Doctor Records
9. View Medicine Records
10. View Prescription Records
11. View Bill Records

OOPS Concepts

- Classes and Objects
- Inheritance
- Encapsulation
- Constructors

Database Tables

- patient
- doctor
- medicine
- prescription
- prescription_details
- bill

How to Run

1. Install Java and MySQL.

2. Create the "medical_pharmacy" database.

3. Add MySQL Connector/J to the "lib" folder.

4. Open the project folder in VS Code.

5. Compile:
   
   "javac -cp ".;lib/*" *.java"

6. Run:
   
   "java -cp ".;lib/*" Main"

Conclusion

This project demonstrates how Java OOPS concepts and MySQL database connectivity can be used to develop a basic Medical Pharmacy Management System.
